# Детекция выстрелов для охраны окружающей среды

## Описание проекта
Проект посвящён разработке прототипа системы автоматического обнаружения
звуков выстрелов по аудиоданным для задач мониторинга экосистем.
Решение ориентировано на выявление фактов браконьерства в природоохранных
зонах, а также на контроль интенсивности стрельбы в разрешённых
охотничьих угодьях, включая ночное время.

Проект демонстрирует применение предобученных моделей машинного обучения
для анализа акустических данных и может служить основой для построения
полноценной системы экологического мониторинга.

---

## Бизнес-задача
В природоохранных зонах и охотничьих угодьях существует проблема незаконной
охоты (браконьерства), особенно в ночное время, когда используются приборы
ночного видения. Традиционные методы контроля (патрули, рейды, видеокамеры)
требуют значительных ресурсов и не обеспечивают непрерывного мониторинга.

Цель проекта — разработать прототип системы автоматического обнаружения
звуков выстрелов по аудиоданным, которая может использоваться:

- для выявления фактов браконьерства в заповедниках и национальных парках;
- для контроля количества выстрелов в разрешённых охотничьих зонах;
- для круглосуточного мониторинга, включая ночное время.

Система должна автоматически анализировать аудиозаписи и определять,
содержит ли запись звук выстрела.

---

## Постановка задачи в терминах Data Science

Область:

Audio ML / Acoustic Event Detection

Тип задачи:

Бинарная классификация аудиосигналов

Объект классификации:

Аудиофрагмент

Классы:

- `1` — звук выстрела (gun_shot)
- `0` — любой другой звук окружающей среды

Формализация задачи:

Для каждого аудиофайла требуется определить вероятность принадлежности
к классу «звук выстрела». На основе выбранного порога принимается
бинарное решение.

---

## Метрики качества
Для оценки качества модели используются следующие метрики:

- Recall — пропуск звука выстрела означает невыявленный факт браконьерства;
- Precision — важна для снижения количества ложных тревог;
- F1-score — итоговая метрика, отражающая баланс между precision и recall.

---

## Данные

В проекте используется датасет UrbanSound8K:  
https://www.kaggle.com/datasets/chrisfilo/urbansound8k

Датасет содержит 8732 аудиозаписи городских звуков,
размеченных по 10 классам, включая класс `gun_shot`.
Для целей проекта все классы, кроме `gun_shot`,
были объединены в единый отрицательный класс.

В рамках проекта была выполнена следующая предобработка:

- приведение всех аудиофайлов к частоте дискретизации 16 кГц;
- преобразование аудио в моно-канал;
- сохранение аудиофайлов в едином формате;
- формирование бинарной целевой переменной `is_gun_shot`.

---

## Модель

В проекте используется предобученная модель YAMNet от Google:  
https://www.kaggle.com/models/google/yamnet/tensorFlow2/yamnet

- модель обучена на крупном датасете AudioSet (более 500 классов звуков);
- поддерживает широкий спектр акустических событий, включая выстрелы;
- принимает на вход аудио с частотой 16 кГц;
- позволяет получить рабочий прототип без дополнительного дообучения;
- широко применяется в исследовательских и прикладных задачах.

---

## Оценка качества
После прогона датасета через модель были рассчитаны метрики:
- Precision == 0.9522
- Recall == 0.5321
- F1-score == 0.6827

Вывод:
У модели минимальное число ложных тревог, однако качетсво детекции выстрелов требует доработки

Ограничения решения:
1) Используемый датасет содержит преимущественно городские звуки, что отличается от акустических условий дикой природы;
2) Возможны ложные срабатывания на резкие импульсные шумы;

1) Установить зависимости requirements.txt
2) Скачать датасет https://www.kaggle.com/datasets/chrisfilo/urbansound8k
3) Запустить convertAudiofilesToMono16Khz.ipynb для приведения аудио к частоте дискретизации 16 кГц
4) Запустить checkDatasetAndPrepareCSV.ipynb для просмотра датасета и обновления .csv файла
5) Запустить yamnetQuality.ipynb для оценки качетства модели YAMNet
